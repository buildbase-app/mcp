# v0

Connect BuildBase to v0 as your own MCP server. v0 uses its tools while it
generates. The app v0 builds cannot call them.

## Where to add it

Open the **+** menu in the prompt form, select **MCPs**, and add a custom MCP
server.

## Settings

| Field | Value |
| --- | --- |
| Name | `BuildBase` |
| URL | `https://api.console.buildbase.app/mcp` |
| Authentication | OAuth |

## Sign in

After you save, v0 opens the BuildBase sign-in page. Sign in with your BuildBase
account and approve the access request.

## Check it works

In a chat, ask:

> List my BuildBase organizations.

## Known limits

- MCP tools are available only during generation, not in the generated app.
- Your chat's permission mode (Ask, Auto or Full) decides whether v0 asks
  before a tool runs. BuildBase still asks for approval in the chat before
  deleting things, changing members or roles, moving money or changing sign-in
  settings.
- Adding a server is done on the desktop site. On iOS you can pick a server you
  already added.
- If the agent says agent access is off, an owner or admin of that organization
  turns it on in **Console > Account > Security**.
